# Archery Range — لعبة محاكاة الرماية

لعبة رماية بالقوس والسهام بمنظور الشخص الأول ومشهد ثلاثي الأبعاد لحظي باستخدام Three.js، مبنية كتطبيق ويب تقدمي (PWA) ومصممة أساساً لشاشات الهواتف.

## التشغيل
- افتح رابط الموقع المنشور عبر HTTPS.
- في Chrome على Android استخدم «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- يمكن تشغيل المشروع محلياً عبر خادم تطوير محلي؛ لا تفتح index.html مباشرة من نظام الملفات لأن Service Worker يحتاج إلى HTTPS أو localhost.

## الموجود حالياً
- شاشة رئيسية وشاشة مستويات.
- ساحة ثلاثية الأبعاد حقيقية باستخدام WebGL وThree.js، بمنظور الشخص الأول.
- خمسة مشاهد بيئية إجرائية: غابة، وادٍ، جبال، صحراء، وميدان بطولة.
- ثلاثة أسهم في كل محاولة.
- رفع وخفض زاوية التصويب ومؤشر لتحديد القوة.
- إطلاق بالضغط المطوّل ثم الإفلات.
- نموذج قوس وسهم ثلاثي الأبعاد وحركة مرئية للسهم أثناء الطيران.
- نموذج باليستي أولي يراعي زاوية التصويب والقوة والجاذبية والرياح المتغيرة المخفية.
- تسجيل نقاط أعلى كلما اقتربت الإصابة من مركز الهدف.
- شرط اجتياز لكل مستوى وإعادة المحاولة عند الإخفاق.
- Manifest وService Worker وتخزين مؤقت لملفات واجهة التطبيق.

## ملاحظات مهمة
- هذه نسخة ثلاثية الأبعاد أولية قابلة للتجربة وليست محاكاة احترافية نهائية. يلزم ضبط الفيزياء والاصطدامات واختبارات الأداء على أجهزة فعلية، كما أن جودة الرسوم تعتمد على قدرة الجهاز.
- النتائج والتقدم لا يتم حفظهما؛ يعاد التقدم عند إعادة تحميل التطبيق.
- اسم Archery Range مؤقت ويمكن تغييره لاحقاً.
- الأيقونة الحالية SVG. يوصى بإضافة أيقونتي PNG حقيقيتين بمقاسي 192 و512 بكسل عند تجهيز الإصدار النهائي لضمان أفضل توافق للتثبيت عبر المتصفحات.
- الأصوات غير مضافة في هذه المرحلة.

## الملفات
- `index.html` هيكل الشاشات.
- `styles.css` التصميم المتجاوب واللمسي.
- `game3d.js` مشهد Three.js ومنطق اللعب والفيزياء الأولية والنتائج.
- `game.js` نسخة الرسم ثنائي الأبعاد السابقة (احتياطية).
- `manifest.webmanifest` تعريف PWA.
- `sw.js` التخزين المؤقت لملفات التطبيق ومحاولة تخزين مكتبة Three.js للعمل دون اتصال بعد أول تحميل ناجح.
- `icons/archery.svg` أيقونة مؤقتة.

## النشر
المستودع جاهز للربط بخدمة استضافة مواقع ثابتة مثل Vercel أو GitHub Pages. يجب أن يكون الموقع منشوراً عبر HTTPS حتى يعمل Service Worker وتتاح متطلبات التثبيت.
